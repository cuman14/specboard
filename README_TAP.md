# Specboard Homebrew Tap

This tap contains the Specboard cask for macOS (Apple Silicon).

Tap repo: [cuman14/homebrew-specboard](https://github.com/cuman14/homebrew-specboard)

## Installation

```bash
brew tap cuman14/specboard
brew install --cask specboard
```

## Upgrading

```bash
brew upgrade specboard
```

## Uninstalling

```bash
brew uninstall specboard
brew untap cuman14/specboard
```

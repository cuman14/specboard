🎯 Specboard — Project Overview

A desktop GUI application for managing OpenSpec changes, artifacts, and specs — visually.

💡 What is Specboard?

Specboard is a Tauri 2 + React 19 desktop application that provides a visual interface for OpenSpec — a Spec-Driven Development (SDD) framework for AI coding assistants. It lets developers manage OpenSpec changes, artifacts, and specs without touching the terminal.

🛠️ Tech Stack

Layer Technology Notes
Desktop Shell Tauri 2 Rust backend, WebView2 frontend
UI Framework React 19 + TypeScript Hooks-first, no class components
Styling Tailwind CSS v4 CSS vars for design tokens
Components shadcn/ui (Radix UI) Copy-paste, fully owned
State Zustand Global stores, no Redux
Routing React Router v7 Client-side SPA inside Tauri
Drag & Drop @dnd-kit Kanban board
Package Manager pnpm NOT npm or yarn

🏗️ Architecture Overview

System Layers

  1. Tauri Rust Backend — IPC commands, file system watcher, OpenSpec CLI subprocess execution
  2. React Frontend — SPA with router, Zustand stores, shadcn/ui components
  3. OpenSpec Structure — openspec/changes/, openspec/specs/, openspec/archive/
